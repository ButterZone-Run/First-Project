## My process

I started by studying the display that was provided in the project zip file. I went over in my head how i would go about achieving what i saw in front of me. Then from there i went into VScode and started writing out the html with the project display page open next to me. After i thought i had what i needed to start styling i went over to the css tab and started adding styling from the top of the page and worked my way down. As i went along i would noted that i needed to add a class attribute or a span element to target specific parts of the page. When i got stuck i would try my best to find the answer and impletment the solution. At first i was commiting and pushing all of my changes that were very small and then going to github to view them in pages but this was very inefficent. I knew there had to be a better way so i finally figured out how to use the preview extensions in VScode. That helped a lot and i was able to get to a decent solution.
